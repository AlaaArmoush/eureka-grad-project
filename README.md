# Eureka

Eureka is an editable physics laboratory for Palestinian Grade 11, Grade 12/Tawjihi and University Physics 101/102 students. Learners build experiments, compare measurements with physical laws and solve challenges. Teachers assign scenes, control permitted changes and review students' work.

Its headless TypeScript engine is built from scratch for seven topics: projectiles; collisions and momentum; rotation, friction and inclines; pendulums, springs and joints; energy and measurement; force fields; and geometric optics. The complete local website includes saved experiments, classes, assignments, a gallery and 21 challenge levels. A full-function Android/iOS application follows the website.
